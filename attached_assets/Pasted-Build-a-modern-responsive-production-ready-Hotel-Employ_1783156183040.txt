The application should have a premium UI similar to Linear, Notion, Stripe Dashboard, and modern SaaS applications.

Theme:

- Professional

Use a component-based architecture.

WEEKLY OFF MANAGEMENT
=========================================

This is one of the most important modules.

Each employee can have different weekly off policies.

Support:

1 Day Every Week

2 Days Every Week

4 Days Per Month

Custom Weekly Off

Rotational Weekly Off

Examples

Employee A

Sunday Off

Employee B

Monday Off

Employee C

4 Off Days Per Month

Employee D

Custom Rotational Schedule

The system should automatically calculate expected working days based on the assigned weekly off policy.

Weekly Off should NOT deduct salary.

Weekly Off should appear separately from Absent.

CONTINUE DUTY
=========================================

Continue Duty is a paid extra working day.

Each employee can have Continue Duty entries.

Example

Employee works on scheduled weekly off.

System adds Continue Duty.

Admin defines payment.

Example

1 Continue Duty = ₹500

Automatically added into payroll.
